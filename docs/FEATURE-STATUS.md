# 덤핑몰 기능 현황 · 2026-09-21

원본 기획: `../../docs/FEATURES.md`. 아래 상태는 실제 구현 기준입니다.

## 이미 사용 가능한 기반

- 공개 상품 탐색, 검색, 카테고리/광역 지역/상태 필터, 정렬, 관심상품
- 이메일 OTP 로그인, 본인 사업자 정보 저장 (진위 확인 아님)
- 상품 단건 등록, 사진 1장 업로드, 판매 종료
- 수량·가격 견적 요청, 가격 재제안, 수락/거절/취소, 거래별 메시지
- 본인 매입/판매 제안과 등록 재고 대시보드
- 대략적인 물류비 계산, 모바일 대응, PWA 설치 및 오프라인 안내

## 이번 작업 (2026-09-26 · 전량경매 설계 문서)

- **즉시체결가**: 공개 가격, 이상 입찰 시 서버에서 즉시 낙찰(동시 구매 1건 보장), 판매자 인상 자유·현재가 초과 범위 인하, 인하 알림.
- **최저낙찰가 완전 비공개**: 금액·도달 여부·마감 사유 모두 판매자·운영자만. 판매 결정 대기도 최고 입찰자 외에는 일반 낙찰처럼 표시.
- **최저가 미달 처리**: 판매자가 24시간 안에 결정하고, 수락하면 최고 입찰가로 바로 입금 대기 주문이 생깁니다(구매자 재확인 없음). 거절·무응답은 유찰. `buyer_only`는 코드에만 남아 있고 쓰지 않습니다.
- **실시간 갱신**: 3초 폴링 + ETag 304, 서버 시각 카운트다운, 입찰자 수, 빠른 입찰 버튼.
- **에스크로 흐름 보강**: 출고 사진 1~5장 필수, 7일 자동 수령 확인, 분쟁 중 정지.
- **분쟁·위약금**: 신고·소명·운영자 처리(기각/취소·환불/부분 환불), 10% 위약금, 미납 시 이용 제한(이후 같은 사업자번호로 가입한 계정 포함), 미입금 자동 위약금, 누적 환불·송금 기록.
- **자전거래 방지**: 사업자번호 체크섬·국세청 상태 조회(키 등록 시), 같은 사업자번호 입찰 차단, IP 해시 기록, 운영자 의심 목록·경매 중단.
- 기본 수수료 3%로 변경. 상세: `docs/WHOLE-AUCTION-2026-09-26.md`. 검증 7개 스위트 488개 검사 통과.
- 2026-09-29 확정 정책: 최저가 미달은 판매자 수락 시 즉시 성사(구매자 재확인 없음), 입금 기한 24시간, 미입금 자동 위약금 끔, 차순위 승계 끔(`AUCTION_SUCCESSION=on`으로 재개 가능).

## 이전 작업 (2026-09-21 밤 · 남은 한계 해소)

- **부분 수량 경매**: 최소 입찰 단위, 단가×수량 입찰·교체, 단가순 배정과 낙찰 하한가, 낙찰자별 주문, 즉시 낙찰 미리보기, 미낙찰 잔여 재경매.
- **차순위 승계**: 미입금·취소 시 최저가 이상 입찰자에게 24시간 제안(최대 2회, 마감 후 7일), 수락·거절·만료 처리, 등록 시 on/off.
- **입금 자동 확인**: 4자리 입금 코드, 입금 원장, 웹훅(`/api/webhooks/deposit`, HMAC 또는 고정 헤더), 매칭 규칙, 운영 탭 입금 관리(수동 입력·연결·무시·재시도).
- **웹 푸시**: VAPID 구독·발송·정리, 서비스 워커 수신·클릭 딥링크, 로그아웃 해제, 앱 배지.
- **매출 관리**: 카테고리별 수수료율, 운영 탭 매출·수수료 패널, 월별 CSV(수식 주입 방지).
- 동시성: 배치 트랜잭션 + 자문 잠금 + 토큰 claim, 금액 오버플로 가드, claim-first 재등록.
- 상세: `docs/AUCTION.md`. 검증 5개 스위트 281개 검사 통과.

## 이전 작업 (2026-09-21 · 전량 경매 프로세스)

- 재고 등록에 **전량 경매** 방식 추가: 기간(3~14일), 시작가, 비공개 최저 매각가.
- 입찰: 호가 단위, 최고 입찰자 표시, 마감 5분 전 입찰 시 5분 연장, 재입찰 알림.
- 기간 절반 경과 시 최저가 미달이면 공급자에게 인하 권고 알림 + 상세 화면 배너. 공급자는 최저가 인하·현재 최고가 즉시 낙찰·입찰 없는 경매 중단 가능.
- 마감 시 자동 낙찰/유찰. 낙찰 시 주문 생성, 48시간 입금 기한, 기한 초과 자동 취소.
- 주문: 입금 신고(구매자) → 입금 확인(운영자) → **상호·연락처·주소 상호 공개** → 출고(공급자) → 인수 완료(구매자) → 수수료 차감 정산(운영자).
- 유찰·기한 초과 재고 다시 경매, 정산 계좌 등록, 앱 내 알림(헤더 종 아이콘·알림 탭), 운영자 탭(입금 확인·정산·주문 취소·누적 수수료).
- 마켓에 "전량 경매" 메뉴, 카드에 현재가·입찰 수·남은 시간.
- 상세: `docs/AUCTION.md`. 검증: `scripts/verify-auction.mjs` 52개 검사 통과.

## 이전 작업

- 구글/카카오/네이버 버튼과 OAuth 연동 코드. 덤핑몰 전용 앱/키 생성 및 Vercel Secret 저장 완료. 실제 OAuth 왕복·구글 공개 설정·네이버 검수는 미완료여서 버튼은 준비 중으로 유지.
- 사업자 주소의 시·군·구를 기반으로 공개 거래 별칭 배정. 상품/거래 화면의 공급자·구매자명에 사용.
- 형용사 20개, 지역별 순차 배정, 같은 지역 저장 시 유지, 다른 지역 변경 시 재배정.
- 번호 없는 조합 소진 후 순번을 붙이는 기본 확장 규칙. 숫자 표기 정책은 추후 변경 가능.
- 상세 주소/실제 상호는 본인 프로필에서만 반환. 주소는 자기신고이며 실재 여부·사업자 소유 확인은 미구현.

## 디자인 선택안

1. [Faire](https://www.faire.com/) — 흰 바탕, 정돈된 도매 상품 카드와 여백.
2. [식봄](https://www.foodspring.co.kr/) — 국내 사업자가 익숙한 검색/분류와 가격 중심 탐색.
3. [B-Stock](https://bstock.com/) — 재고 처분의 수량, 상태, 마감 정보 구성.

사용자 선택: **식봄처럼 익숙한 국내 도매몰**. 큰 배너를 짧은 재고 특가 안내로 줄이고, 검색·카테고리·빠른 조건 필터·4열 상품 카드로 구성. 덤핑몰의 주황색 브랜드는 유지하고 MOQ·잔여 재고·별칭을 카드에 표시.
